## 旋钮名勘误

任务书写的 `valueBetEqRiverDiscount` 在 `DEFAULT_BRAIN_TUNING` 中不存在；实际旋钮为 **`valueBetRiverDiscount`**（默认 0.03，`src/lib/ai/brain.ts:523`，语义见 `brain.ts:911`：河牌时从价值下注门槛中减去该值）。已按正确名称实验。200 手 smoke 验证：配对 B 座位 0 的 tuning 字段正确回显 `valueBetEqHU=0.48`，配对机制工作正常（配对 A 在三场 seed42 比赛间逐座位利润完全一致，证明发牌确定性正确）。

## 判定清单

- **valueBetEqHU=0.48：拒绝采纳**（证据不足）。点估计为负（-31.2），CI 大幅跨 0。核心问题「更薄的价值下注在 gto 内战是否盈利」的答案：**无任何盈利证据，方向反而偏负**，但远未到显著，不能断言默认 0.52 更优。
- **valueBetEqHU=0.56：拒绝采纳**（证据不足）。两个种子点估计均为负（-591.7 / -5.0，合并 -16.6），合并 CI [-186.9, +153.6] 跨 0。
- **valueBetRiverDiscount=0.06：拒绝采纳**（证据不足）。两个种子点估计均为负（-572.1 / -5.9，合并 -6.1），合并 CI [-29.0, +16.8] 跨 0。这是三个变体中信息量的一个（CI 最窄），可认为河牌折扣加倍「无害但也无益」，真值大概率在 ±20 bb/100 以内。

三个变体、五场配对赛的座位 0 点估计**全部为负**——方向一致地不利于改动，但按严格判定规则（CI 完全 > 0 且中值 > +15 才采纳；CI 完全 < 0 才记为默认更优）三组 CI 均跨 0，结论统一为「证据不足，保持默认 0.52 / 0.03」。

## 台架观察（值得锦标赛组织者注意）

1. **座位 0 差值方差被少数全下巨pot主导**。seed42 的两场（hu056 / riverdisc006）座位 0 CI 半宽高达 ±1200 bb/100：座位 0 基准位盈利 +426.9 bb/100（59 次 rebuy），换参数后 rebuy 飙到 127-133 次——门槛改动在几手 100bb 全下里翻转了动作，单场 8000 手不足以消化这种尾部事件。seed43 没有此类巨pot，CI 立刻收紧到 ±23 ~ ±172。
2. 含义：对价值门槛这类「效果靠大量小底池累积」的旋钮，单场 8000 手配对赛的座位 0 CI 可能被 1-2 手牌撑爆。**建议后续此类实验直接跑 2 个种子合并**（或单场 ≥16000 手），并把 rebuy 次数差作为「是否有巨pot污染」的体检指标。
3. hu048 单场 CI ±616 且中值仅 -31：即使加跑 seed43，按 hu056/riverdisc006 的经验合并后也只能收窄到 ±300 量级，不可能越过 +15 采纳线（点估计方向为负），故按规则未加跑。
4. 配对机制本身健康：座位 0 以外座位的 diff 在 smoke 中多为 ~0，正式赛中其他座位的大幅波动（如 hu056 seed42 座位 3 +1077.6）是座位 0 打法变化在共用手牌中的正常传导，均非变量座位，不影响判定。
