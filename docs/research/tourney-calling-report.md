# 跟注松紧组（calling）锦标赛报告

实验组：跟注松紧。基线 = gto 默认 tuning（equityIterationsScale=0.25），6 人桌，配对种子模式
（同一批发牌打两遍，唯一变量 = 座位 0 的旋钮），diff = B(变体) − A(默认)，bb/100。

## Smoke 验证（200 手，seed 42）

- `callMarginDelta=-0.03`：200 手零决策分歧（翻转带仅 0.03 宽，样本小属正常），结果 JSON 的
  `b.seatBrains[0].tuning` 正确回显旋钮。
- 用 `callMarginDelta=-0.20` 做链路验证：座位 0 diff +124.9 bb/100（CI [-327.6, +577.5]），
  确认旋钮真实到达决策路径、配对管线工作正常。
- `ffe-008` 正式赛结果 JSON 回显 `foldFloorEq=0.08`，拼写无误。

## 解读

1. **默认跟注边际既未被证明过紧也未被证明过松。** ±0.03 的 callMarginDelta 在 16000 配对手上
   只翻转了 ~2-5% 的决策（seed42: 288/391 手、seed43: 444/368 手有非零 diff），且合并 CI 宽度
   仍达 ±640 bb/100，远超 ±15 的采纳门槛。两个方向的点估计在不同种子间不稳定
   （-575 → -27.5 / +1.4），是典型的轨迹噪声特征而非真实 EV 信号。
2. **foldFloorEq=0.08 是退化变体**：与默认 0.12 在 8000 手上逐比特一致（零决策分歧）。原因：
   gto 的跟注门槛 required + callMargin(≈0.03+) + perOpp 项恒高于 0.12，eq < 0.12 的手面对
   任何注额本就会被门槛规则弃掉；floor 规则（eq < floor 且 betFrac > 0.75）永不在门槛之前
   改变结果。对 gto 风格该旋钮当前是死参数，无需复跑 seed 43。

## 意外发现（台架层面，供主 agent 参考）

1. **筹码跨手结转使配对 CI 爆炸。** 首次决策分歧后座位 0 的筹码轨迹与 A 脱钩，后续同一手牌
   即使决策相同，绝对筹码额也不同：单手 diff 最高达 ±276,015 筹码（≈27,600 bb，起点筹码仅
   1000）。8000 手配对 CI 宽达 ±1200 bb/100；三个旋钮方向相反的变体在 seed 42 齐刷刷落在
   ≈-575、seed 43 齐刷刷落在 ≈0，证明该量级是纯轨迹噪声。**结论：当前台架配置（筹码结转 +
   100bb 起始 + 破产才重置）在 8000-16000 手尺度上无法分辨 ±15 bb/100 级别的跟注参数效应。**
   若要可判定，建议每手重置筹码到 startStack，或按有效筹码归一化盈亏后再算 bb/100。
2. **基线重尾方差**：seed 42 的 A 场（6 个完全相同 brain）座位间 bb/100 从 -228 到 +427，
   座位 0 单手 sd 高达 574 bb；rebuy 频繁（座位 0 在 A 59 次、B 场 120-129 次）。
3. A 场跨结果文件逐比特一致（三次实验的 A 完全相同），台架确定性可复现性良好；
   旋钮名错误未被静默忽略的问题不存在——链路验证（-0.20 大扰动）产生了非零 diff。
