# 锦标赛报告 — bluff 组（诈唬频率/尺度）

- 实验组：**bluff**，关注 gto 内战里诈唬多一点还是少一点盈利
- 台架：`scripts/selfplay/.dist/run.cjs` 配对种子模式（同一 masterSeed 两遍，唯一变量 = 座位 0 参数）
- 配置：6 人桌，5/10 盲注，起始 1000（100bb），每场 8000 手 × 2 遍，全部座位 gto + `equityIterationsScale=0.25`
- 判定规则：采纳 ⇔ 配对 diff 95% CI 完全 > 0 且中值 > +15 bb/100；CI 完全 < 0 → 默认更优；CI 跨 0 → 证据不足，保持默认
- smoke 验证：200 手配对跑通，结果 JSON 的 `b.seats[0].tuning` 正确回显 `pureBluffK` / `pureBluffFrac` / `semiBluffK`（旋钮名已对照 `src/lib/ai/brain.ts` 的 `DEFAULT_BRAIN_TUNING` 确认）

## 判定清单

- 采纳：无
- 拒绝（默认更优，CI 完全 < 0）：无
- 证据不足，保持默认：全部 4 个变体

## 解读

1. **四个变体、两个种子的全部 7 次测量 diff 均为负**（-590.5 / -7.2 / -124.6 / -73.7 / -2.5 / -10.0 / -16.2）。没有任何变体达到统计显著，但方向上 100% 一致为负——无论诈唬调多还是调少、调频率还是调尺度，都倾向让座位 0 变差。这软性地暗示默认诈唬参数（pureBluffK=0.6 / pureBluffFrac=0.5 / semiBluffK=0.35）在 gto 内战里接近局部最优。
2. pureBluffFrac=0.67 的合并中值 -92.4 是除噪声外最大的信号，且 CI 最窄（尺度类旋钮不改动行动序列，配对设计降噪最有效）。两个种子都是负值，如果再加种子收紧 CI，它是最可能被判「默认更优」的候选——但按现行规则只能记为证据不足。
3. pureBluffK=0.35 在 seed=42 的 -590.5 看似灾难，seed=43 仅 -2.5——证实那是极少数怪物底池（全下 100bb 级别）主导了整场的噪声，不是真实效应。

## 台架观察（给其他组参考）

- **方差极大**：100bb 深筹 + 激进 gto，每座位每 8000 手破产 56~189 次（约每 50~140 手一次全下），单座位 bb/100 的 95% CI 宽达 ±1200。
- **配对降噪效果取决于旋钮类型**：频率类旋钮（pureBluffK、semiBluffK）改变「是否下注」，行动序列分歧后手内 RNG 消费序列错位，混沌放大，配对 CI ±600~1200；尺度类旋钮（pureBluffFrac）只改下注额，行动序列保持一致，配对 CI 仅 ±150~250。频率类旋钮用 8000 手配对赛基本欠功率，建议后续对频率类旋钮用更多手数或更多种子合并。
- **怪物底池溢出效应**：座位 0 分歧手会把 ±1000 bb/100 的摆动传染给其他座位（如 semiBluffK-0.5 seed=43 的 seat3 -1007.4 / seat4 +1041.6 镜像差值），这不影响座位 0 的配对分析，但说明单场单种子的座位 0 中值也可能被 1~2 个全下锅主导。
- 吞吐：4 任务并行 + 其他 agent 负载下约 5.1~5.7 hands/s（每遍 8000 手约 24~26 分钟），3 任务并行约 7.8~7.9 hands/s。
