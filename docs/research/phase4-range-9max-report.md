## 解读

- **量级**：9max 下 +85.7 bb/100 ≈ 6max 烟测的 +82.8，范围引擎价值不随桌型衰减。
  9 人桌面对下注/加注的决策点更多（多人底池、更多加注战），按对手隐含范围算
  equity 替代「vs 随机范围」的收益在 9max 同样充分兑现。
- **机制一致性**：其余 8 座每场平均 diff ≈ -9~-13 bb/100，8 座合计 ≈ -86，
  与座位 0 的 +85.7 零和对冲（逐场 Σdiff = 0，已校验）。收益来源是旧脑座位
  面对座位 0 时用随机范围高估/低估 equity 造成的系统性错价被范围脑反向收割。
- **风格统计不变**：座位 0 的 VPIP/PFR 在 A/B 两遍完全一致（如 seed 42：
  24.3%/24.3%、12.0%/12.0%），范围引擎只改变面对下注/加注时的 equity 口径，
  不改变入池/加注频率，无意外行为漂移。
- **单场波动**：diff 范围 +58.5 ~ +101.0，sd/手 ~13bb 稳定；最低场（seed 49）
  是因 A 场座位 0 本身运气极好（+64.4 bb/100），并非范围脑收益消失。
- **意外发现**：无负面发现。唯一注意点是 9max 单场速度 ~6.6 hands/s
  （多 agent 并行竞争 CPU 所致，任务内无错误、无超时）。
