## 结论与推荐

总均分排名：**data 8.00 > slim 7.69 > full 7.08**。

**推荐默认复盘风格：data（slim 骨架 + 关键街实算胜率/所需胜率注入）。**

- 与决策 prompt 大战不同：复盘是分析任务，客观数据注入不仅无害，而且修复了 slim 的最大病灶——凭空编造赔率/胜率数字（slim 在 hw3 编造底池赔率 765/17%，实际 525/23%，得分全场最低之一 4.0；data 同手 8.8 全场最高）。
- data 在准确性（8.33）与洞察力（8.25）两维第一：典型如 bt2（顶两对打光）8.3 vs full 5.3；且未被数据带偏——hw5 泡沫 ICM 手中 data 明确写出「胜率合格不等于锦标赛决策合格」（66%>43% 仍应弃牌），评委给 9/8/9/8。
- 生产版 full 垫底（7.08）：说教模板没有换来质量，准确性/可操作性/洞察力三维全部最低；唯一第一是简洁性（8.17），其 80 字/comment 硬约束确实有效。
- data 的唯一短板是简洁性（7.17，「冗长」被评委点名 4 次）；hw2 它把明显的河牌错失价值误判为可接受（5.5 分）说明数据不是免错金牌。
- 落地建议：生产 prompt 改为 slim 骨架 + 关键街胜率注入，并保留 full 的每条 comment 字数硬约束；若短期不想接入 equity 实算，slim 也明显优于现状 full（+0.61）。
- 置信度：12 手样本，data 领先 slim 0.31 分属弱证据，领先 full 0.92 分较可信；「full 说教版最差」与决策 prompt 大战结论方向一致。

## 局限

- 评委与被测教练同为 k3，存在同源偏好风险；盲评打乱只消除顺序偏差。
- 实战手牌（台架日志）只有 hero 动作，对手动作/底池演变未知，分析深度受限。
- 样本 12 手，维度差 <0.5 分不足以下强结论。
- data 变体的胜率按随机对手计算（非对手范围），与实战口径有差距。
