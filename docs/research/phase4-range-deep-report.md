## 解读

1. **深度放大确认**：范围引擎净效应 100bb 烟测为 +82.8 [+34.8, +130.9]（3000 手），200bb 本实验为 +156.8 [+139.3, +174.2]（8 万手），约翻倍。与「护栏价值 ∝ 深度」（Phase 3：护栏 100bb ≈ 0、200bb +19.9）同方向且幅度大得多——200bb 下范围引擎单项（+156.8）远超护栏单项（+19.9），深筹码场景范围引擎是主要价值来源。
2. **桌型无差异**：6 人桌 +154.9 vs 9 人桌 +158.7，合并 CI 几乎重合。范围引擎的座位 0 边际价值对桌型不敏感（9 人桌对手更多但每人被抽水份额相应摊薄）。
3. **零和再分配一致**：全部 16 个半程零和精确为 0、rebuys=0；对手座位 diff 全部 ≤0（多数显著为负），座位 0 的 +157 bb/100 来自旧脑对手，机制自洽。
4. **口径注意**：本场效应是「1 个范围座 vs 全旧脑桌」的边际价值。生产若全桌 AI 都开范围，座间互相挤压后单座净优势会小于此值；本实验验证的是引擎本身的 EV 方向与量级，不是全开后均衡组成。A 场旧脑座位 0 在 200bb 对旧脑场基本打平（均值 +3.4 bb/100），说明 +156.8 不是座位/发牌伪影。
5. **B 场座位 0 绝对盈率 +148~+215 bb/100**：200bb 深度下旧脑场对范围座的支付巨大，与 Phase 2「深筹码漏勺随深度放大」的结构性结论一致——范围推断（面对下注/加注按隐含范围算胜率）精准击中了深筹码下旧脑 vs 随机范围胜率高估的漏勺。

## 意外发现 / 备注

- 无异常：VPIP/PFR 在 A/B 间逐座一致（范围引擎不改变翻前入池率，符合预期——它作用于面对下注/加注时的胜率评估）。
- 运行耗时：总墙钟约 129 分钟，超 100 分钟预算。原因是同机 4 个并行 agent 竞争 CPU（早期 6-7.5 hands/s，后期其他组结束后回升至 9.8 hands/s）。单进程最远 62 分钟 < 5400s 超时上限，无超时风险。
- 并发纪律：全程 ≤3 个 node 模拟进程（滚动补位），仅构建 merge-paired 一次，未改动任何 .ts/.tsx。
