# LLM 模型大战实验报告（2026-09-24）

## 实验设置

- 8 人桌，盲注 5/10，起始 1000（100bb），resetStacksEachHand
- 座位 = 4 模型 × {agent 层, 裸模型}：K3（moonshot:k3，订阅端点）、K2.7 替身（kimi-for-coding）、DeepSeek Flash、DeepSeek V4 Pro
- 实战参数：思考模式开、reasoning_effort=high、maxTokens=384000、上下文携带 20 手回顾（agent 组）
- 大混战 200 手同桌对抗（seed 42，97 分钟）；配对赛各 300 手（Flash，同种子同发牌，启发式围猎桌）
- agent 层 = 生产 prompt（策略常识 + brainStats 胜率注入 + 对手画像 + 20 手回顾）；裸模型 = 极简规则 prompt

## agent 层净效应（agent − raw，负 = agent 拖后腿）

|---|---|---|
| K3 | -374 | — |
| K2.7 | +65 | — |
| Flash | -243 | -244.6（低参数）/ -123.9（思考high），CI 均跨 0 |
| Pro | -120 | — |

**6 个独立对照中 5 个方向为 raw 更优**（仅 K2.7 例外）。逐手分析：agent 组赢面更广（40 vs 34 手）但赢的锅更小——保守打法赢小输大。

## 结论与注意

1. 当前 agent 层 prompt（策略说教 + 数据注入）对 LLM 牌力无正贡献，方向一致为负；最可能的机理是过度约束导致打法可预测/偏紧弱被剥削
2. 统计功效声明：每格样本 200-300 手，单格 CI 很宽（±200+ bb/100）；但 6 个独立对照方向一致，模式可信
3. DeepSeek 思考模式 high 下单决策 10-66s；Pro 思考量最大（单决策 ~2k 输出 token）
4. Kimi 侧为订阅 key（api.kimi.com/coding/v1），不按 token 计费；K2.7 无明确 id，用 kimi-for-coding 顶替
5. 下一步：prompt 瘦身 A/B（数据注入保留、策略说教删除）vs 现 agent vs raw
